# Panduan O-KIM — Versi Tanpa Gambar

Folder ini berisi **versi teks saja** dari panduan yang ada di `dokumentasi/`.

Nama file **sama persis** dengan versi bergambar; isinya juga sama — hanya **seluruh gambar (screenshot) dihilangkan**.

| File | Isi |
|---|---|
| `transportir.md` | Panduan Transportir |
| `tad.md` | Panduan TAD (HSSE / Distribusi / QQ) |
| `pengawas.md` | Panduan Pengawas fungsi |
| `ftm.md` | Panduan Fuel Terminal Manager |
| `adminverivikasi.md` | Panduan Admin Verifikasi |
| `superadmin.md` | Panduan Super Admin |
| `kim-sementara.md` | Alur KIM Sementara (dispensasi) |

**Kapan dipakai versi ini?**

- Untuk dibagikan sebagai dokumen teks / cetak hitam-putih
- Saat screenshot belum tersedia
- Untuk dibaca cepat tanpa memuat gambar

> Versi bergambar ada di folder induk (`dokumentasi/`), dengan gambar di `dokumentasi/gambar/`.
